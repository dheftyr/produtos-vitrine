# Vitrine de Produtos

Este projeto foi desenvolvido para a disciplina de Construção de Sites 2. A proposta é criar uma página para exibir produtos utilizando HTML, CSS e JavaScript.

## Sobre o projeto

Os produtos são carregados a partir da API [DummyJSON](https://dummyjson.com/products). Na página, são exibidas informações como nome, descrição, categoria, preço e imagem de cada produto.

A ideia é permitir que o usuário visualize os produtos e também possa cadastrar, editar e excluir itens.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Axios
- API DummyJSON
- Git e GitHub

## Funcionalidades

- Exibir a lista de produtos.
- Mostrar as informações de cada produto.
- Cadastrar novos produtos.
- Editar produtos existentes.
- Excluir produtos.

## Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/dheftyr/produtos-vitrine.git 
   ```

2. Entre na pasta do projeto:

   ```bash
   cd vitrine-produtos
   ```

3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server do VS Code.

## Observação

A API DummyJSON é utilizada para fins de demonstração. Por isso, alterações feitas por meio das operações de cadastro, edição e exclusão podem não ficar salvas permanentemente.
